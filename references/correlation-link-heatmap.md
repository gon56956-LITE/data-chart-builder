# Correlation-link heatmap

Use this optional composite when the question requires both relationships among predictors and their relationships to an outcome. The [synthetic visual example](../assets/correlation-link-heatmap-example.png) and [reproducible example script](../scripts/correlation_link_example.py) show a two-layer version. Keep a plain matrix, bar chart, or grouped analysis when it answers the question more clearly.

- Upper triangle: show pairwise association among appropriate variables, with a diverging color scale fixed at -1 to 1 for Pearson or Spearman r. If square area encodes |r|, side length must be proportional to sqrt(|r|). Label the statistic, sample handling and population. Keep variable order consistent between all layers; place names on the diagonal or axes.
- Outcome links: each line connects a variable to the outcome and represents an explicitly named, estimated association. Provide a separate legend for its color, width, line style and any p-values. Only present p-values or significance styles when computed using an appropriate method; report sample size and multiple-testing treatment when relevant. Coefficients from a mixed-effects model are not automatically correlation coefficients; identify their units, direction, model adjustment and random effects, and use r notation only when justified.
- Optional model importance: add only when an existing or purpose-built validated model answers the user question. State model, metric, evaluation scheme, sample size and sorting criterion; permutation importance can be negative and is not a signed effect. Do not imply causal direction from importance.
- Match methods to data types, missing values, repeated observations and clusters. Avoid Pearson correlation on nominal category codes, serial identifiers or dates merely encoded as numbers. Use appropriate comparisons, effect sizes or grouped views instead. A significant link is not proof of causation; non-significance does not establish no effect. High importance with a nonsignificant linear association may reflect several causes, not necessarily nonlinearity.
- Use distinct legends and labels when layers have different populations, methods or scales. Include the outcome definition and units. Allow correlation-only or links-only variants without a model.
